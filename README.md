# Material Hub

Designer-focused Windows desktop app for centralized material search.

## V1.1
- Enter-to-search
- Multi-source search launcher
- Search history
- Favorites shell
- Custom source management with `{keyword}`
- Light/dark appearance
- Tauri Windows packaging

## Windows build
GitHub Actions builds Windows `.exe` and `.msi` installers automatically after a push to `main`, or manually from Actions → Build Windows.

Third-party sites are opened through their own search URLs. Direct image aggregation should use permitted APIs/feeds rather than unauthorized scraping.
